## Reproducing a job

```bash
ssh -F ~/.ssh/config_server server 'bash -lc "
  cd /home/luck/rxw/AIM3_remote/AIM3 && bash server/jobs/batch1.sh <stage> <args>"'
python3 server/jobs/collect.py            # pull logs + merge the CSVs into results/
python3 server/jobs/summarise_batch1.py --inject results/REPORT_server_batch1.md
```

Each job's `.meta` records the commit it ran at, so a row can always be traced back to the code
that produced it.
